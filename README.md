# Небесный рубеж

3D-стратегия в реальном времени: городская экономика, дороги, нефть, воздушные налёты, ПВО и наземная армия. Текущая версия — **8.10.2**.

## Запуск

Откройте `Играть.cmd` или [play/Skyfront.html](play/Skyfront.html) в Chrome/Edge. Для одиночной игры установка пакетов и подключение к интернету не нужны. Готовый HTML включён в репозиторий.

Перед переходом закройте вкладку предыдущей версии: локальные HTML в одном профиле Chrome используют общее сохранение. Для переноса между браузерами или профилями доступны «Экспорт» и «Импорт» в настройках.

В 8.10 кооператив — **два отдельных города игроков против двух городов ботов**. Штабы стоят квадратом: до союзника и противника напротив по 2030 м. Каждый управляет своим бюджетом, производством и армией; союзные города и войска видны синими. Победа наступает после уничтожения обоих вражеских штабов.

На карте **два центральных склада** — по одному на северном и южном сухопутном пути. Каждый действующий склад даёт владельцу +15% к производству денег, сплавов и нефти, а также 30 денег и 6 сплавов в минуту. Бонусы двух складов складываются до +30%; содержание армии не дорожает. Восемь заброшенных поселений стоят по краям: четыре на каждом берегу, в кооперативе по два возле каждого города. Подведите дорогу от своего штаба: подключённое поселение приносит 36 денег и 3 сплава в минуту. Разрыв дороги или противник у поселения останавливает доход. Вражеское поселение захватывает пехота, для дохода затем нужна своя дорога. Боты соблюдают те же правила и платят за дороги.

Карта открыта без тумана войны; записанные шаги и моторы, физический обмен боезапаса и автоматическая ремонтная служба сохранены. [Полный чеклист запросов](docs/REQUESTS_CHECKLIST.md) содержит прежние требования, заменённые решения и ограничения. [Изменения и проверка 8.10](docs/qa/AUDIT-810.md).

В 8.9 убраны лаборатории и исследования. Улучшения оплачиваются деньгами прямо в карточке объекта: растут точность, темп огня и дальность, меняется модель. Вооружение доступно сразу, если построена нужная производственная база и хватает ресурсов:

| Производство      | Что выпускает                                                   |
| ----------------- | --------------------------------------------------------------- |
| Казармы           | Пехота, МОГ, противотанковые расчёты, операторы FPV, санитары   |
| База дронов       | Дроны и ракеты; медленный самостоятельный пуск дронов           |
| Бронезавод        | Бронемашины, танки, мобильное ПВО, артиллерия, РСЗО и снабжение |
| Завод боеприпасов | Патроны, снаряды и ракеты ПВО; собственные машины доставки      |

Готовые дроны доставляются на пусковые площадки, крылатые и баллистические ракеты — к ракетным установкам. Местный запас и занятость доставки видны в карточке выбранного объекта.

**E — арсенал, F — армия.** Задайте желаемое количество каждого типа: например, 50 стрелков, 5 танков, 2 тяжёлых танка и машины снабжения. Пополнение работает постоянно, оплачивает обычную подготовку, учитывает живых бойцов и очереди, заменяет потери. Оно сохраняет 250 денег, 5 сплавов и, для техники, 5 нефти. Значение 0 останавливает пополнение выбранного типа. Можно по-прежнему отправлять отдельные партии в точку или атаку.

Защитники самостоятельно распределяются по двум сухопутным коридорам, занимают отдельные посты, захватывают ближайшие нейтральные объекты, окапываются и дозированно усиливают прорыв. Ручные приказы сохраняют приоритет. Ремонтная служба обслуживает город, санитары и снабжение помогают армии.

Техника стала дороже, особенно в сплавах: тяжёлый танк — 3000 денег / 260 сплавов / 70 нефти, РСЗО — 2800 / 240 / 52. Цены и расход нефти дронов сохранены. Только здания дорожают по числу покупок одного типа: 50%, 75%, 100%, 125%, затем 150% базовой цены.

Боезапас конечен: завод производит его за ресурсы, машины физически развозят груз без обязательной дороги к получателю. Ремонтные бригады также ездят по полю. Площадки дронов и ракетные пусковые имеют местный запас и ограниченный темп пуска; улучшения повышают их возможности. Дороги остаются важны для городской экономики и производства.

Карта — **4000 × 3200 м**, море расширено поперёк до 1200 м, расстояние между штабами — 2030 м. Старые кампании переносятся однократно, оплаченные очереди сохраняются. За действующие старые лаборатории и незавершённые исследования возвращаются ресурсы; индивидуальные уровни сохраняются. [Подробные правила и совместимость 8.9](docs/PRODUCTION-89.md).

WASD и стрелки двигают камеру, колесо меняет масштаб, перетаскивание ПКМ поворачивает её. Короткий ПКМ отдаёт приказ выбранной армии или отменяет инструмент. Пробел — пауза. ЛКМ в арсенале отправляет выбранную партию; можно рисовать маршрут через точки. Линия фронта скрыта до включения режима под миникартой.

## Игра вдвоём через интернет

Хозяину нужен Node.js 24+. Откройте ярлык **«Небесный рубеж — по сети»** или **`Играть через интернет.cmd`** и оставьте окно сервера работающим. Зависимости подготовятся автоматически. Создайте дуэль или «Общий фронт» (два города игроков против двух ботов), скопируйте приглашение и передайте другу. Другу достаточно открыть ссылку в Chrome/Edge. Оба нажимают «Я готов», создатель запускает матч.

Открытие HTML само по себе не запускает сервер. Если при создании комнаты появляется «Сервер недоступен», запустите игру через сетевой ярлык и создайте комнату в открывшейся вкладке. В 8.10.1 эта инструкция видна сразу в сетевом меню автономного HTML; сообщение о восстановлении места появляется только после реального входа в комнату.

В 8.10.2 сетевой клиент получает изменения мира вместо повторной передачи полного состояния. По медленному соединению сервер хранит только один неподтверждённый снимок и один будущий свежий снимок; команды и проверка связи обслуживаются отдельно. Частота передачи подстраивается под соединение и затраты подготовки данных, расчёт боя остаётся серверным. Для использования исправления запустите новый сервер, создайте новую комнату и отправьте другу новое приглашение. Подробности объектов свёрнуты, улучшение и ремонт доступны сразу без прокрутки карточки.

[Нагрузочные проверки и ограничения 8.10.2](docs/qa/NETWORK-8102.md) содержат сравнение трафика, реальные WS-прогоны с задержкой подтверждений и проверку карточек.

Публичное подключение использует localhost.run с резервом Cloudflare Quick Tunnel; приглашение действует, пока запущен сервер. В дуэли экономика равна. В кооперативе союзники сохраняют отдельные деньги и запасы, а оба бота получают одинаковый бонус выбранной сложности. Локальные сохранения не заменяются сетевыми снимками. Старые одиночные кампании сохраняют свои два города, постройки, ресурсы и оплаченные очереди. [Подключение, возврат и ограничения](docs/MULTIPLAYER.md).

## Разработка

Рабочая копия 8.10.2 — `igrulka-8102`, ветка `codex/network-performance-8102`. Предыдущие рабочие копии и пользовательские партии не перезапускаем при разработке.

```sh
npm ci
npm start
npm run check       # формат, lint, тесты и автономная сборка
npm run test:soak   # длительные кампании
npm run build      # play/Skyfront.html
```

Начните с [мастер-плана](docs/MASTER_PLAN.md), [карты кода](docs/CODE_MAP.md) и [правил работы](AGENTS.md).
