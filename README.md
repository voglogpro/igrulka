# Небесный рубеж

3D-стратегия в реальном времени: строительство города, дорожное снабжение, экономика, налёты, ПВО, пехота и техника. Текущая игровая версия — **8.3.0**.

## Как играть

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте `Играть.cmd` или [play/Skyfront.html](play/Skyfront.html) в Chrome/Edge. Готовый HTML уже включён: интернет, Node.js и установка пакетов для игры не нужны.

В новой версии: выбор режима и сложности бота на старте, дерево исследований (E), набор армии (F), лестница техники от бронеавтомобиля до тяжёлого танка, РСЗО с ракетными следами и зрелищное разрушение зданий.

Управление: WASD — движение камеры, перетаскивание ПКМ — ракурс, колесо — масштаб, пробел — пауза. В панели B выберите бойца и ×1/×5, затем нажмите на место назначения: он подготовится в казармах и пойдёт туда. Отряды выбираются карточкой или рамкой ЛКМ. Подробные правила и клавиши — в [руководстве игрока](docs/GAMEPLAY.md).

Выбранной армии отдавайте приказы коротким ПКМ. «Линия обороны» / L позволяет провести линию ЛКМ и расставить войска; «Охрана» включает самостоятельную защиту постов и помощь соседям. Набор разделён на пехоту, технику и ПВО, а автонабор включается и отключается для конкретных казарм. Бойцы получают опыт за настоящий урон, используют стены и руины. [Правила новых механик](docs/NIGHT_GAMEPLAY.md).

В 8.2 пехота захватывает четыре стратегических района: склады дают сплавы, узлы связи — деньги и науку. Инфраструктуру можно разрушать и восстанавливать. Shift + ПКМ добавляет точки маршрута армии; БТР умеет доставлять и автоматически высаживать десант. В арсенале заводам можно задать план пополнения склада с резервом денег и сплавов. [Правила районов, маршрутов и производства](docs/EXPANSION_82.md).

В 8.3 набор получил отдельные точки назначения для каждой партии и автоматические карточки отрядов. Исправлены площадной урон пуль, выбор наземных целей и разворот дронов на обходном маршруте. ПТРК и противотанковая машина дополняют танки. Переработаны отрисовка статичных объектов, отсечение леса и пехоты, свечение и расход пикселей на экранах высокой плотности. [Подробности и ограничения](docs/ARMY_83.md).

Обновление боя: Tab / Shift+Tab переключают отряды с переводом камеры, точка выбирает бойца без приказа, двойное нажатие цифры группы наводит на неё камеру, двойной клик выделяет всех таких же бойцов на экране. Прижатая огнём пехота сама ищет укрытие, бойцы добивают раненых и не тратят выстрелы на обречённые цели, ПВО делит цели между установками, а дроны под захватом уклоняются. У каждого класса оружия своя дульная вспышка, гильзы и дым; снаряды Gepard рвутся в воздухе, ЗУР оставляют сплошной след. [Подробности](docs/GAMEPLAY.md).

Далее: компактная панель армии по типам войск, самоходная гаубица с навесным огнём, стрельба очередями, цветные трассеры с рикошетами, новые модели бойцов, реалистичный звук выстрелов с эхом и сирена воздушной тревоги.

## Игра вдвоём

Откройте `Сетевой сервер.cmd` или выполните `npm run multiplayer` после установки зависимостей. Серверу нужен Node.js 24+, клиентам достаточно браузера. Откройте показанный адрес, выберите «Сетевая дуэль», создайте комнату и передайте код второму игроку. Оба подтверждают готовность; матч начинает создатель.

Это LAN preview: два человека, равная экономика, симуляция на сервере, восстановление места после обрыва связи. Одиночные кампании сохраняются отдельно. [Запуск, устройство сети и ограничения](docs/MULTIPLAYER.md).

## Как разрабатывать

Нужен Node.js 24 или новее:

```sh
npm ci
npm start
```

Сервер напечатает адрес `http://127.0.0.1:8787` и на Windows откроет игру. После изменения исходников обновите вкладку. Остановка сервера — Ctrl+C.

```sh
npm run check        # форматирование, анализ кода, тесты, сборка
npm run build        # обновить готовую игру play/Skyfront.html
npm run format       # привести исходники к общему оформлению
```

## Структура

```text
src/game/        правила и состояние игры без браузера и Three.js
src/rendering/   сцена, камера, освещение, модели и эффекты
src/ui/          интерфейс и команды игрока
src/audio/       процедурный звук
src/network/     команды, представление сторон и сетевой клиент
server/          комнаты и авторитетная сетевая симуляция
assets/fonts/    локальные шрифты и лицензии
vendor/three/    Three.js и его лицензия
scripts/         запуск сервера и сборка автономного HTML
tests/           логика, браузерные проверки и длинные кампании
play/            готовая игра; генерируется из src/
docs/            правила, архитектура, разработка и история версий
archive/legacy/  старый прототип для отдельных регрессионных тестов
```

GitHub Actions проверяет исходники, тесты и соответствие готового HTML сборке при push и pull request. Снимки браузера, отчёты, временные файлы и `node_modules` сохраняются локально и не попадают в Git.

Модели, эффекты, текстуры и звук процедурные; характеристики вооружений вымышлены. Сторонние компоненты и их лицензии перечислены в [NOTICE.md](NOTICE.md).
