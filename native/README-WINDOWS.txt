НЕБЕСНЫЙ РУБЕЖ — NATIVE 0.1
Godot .NET / правила 8.16

Запуск: Skyfront.exe. Интернет, браузер и установленный Node.js не нужны.
Вся папка необходима для игры: не переносите один EXE отдельно.

WASD — движение камеры; колесо — масштаб; ПКМ с перетаскиванием — ракурс.
Q / R — поворот. ЛКМ — выбрать; рамка ЛКМ — выделить отряд.
ПКМ по земле — движение выделенных, Ctrl+ПКМ — движение с атакой.
E — арсенал; F — армия. Пробел — пауза; Esc — отменить инструмент/меню.
F5 — сохранить, F9 — загрузить последнее сохранение.

Постройте жильё, электростанцию и промышленность у подъездной улицы штаба.
Дорога: выберите начало, затем конец; следующий клик продолжит улицу.
ПКМ отменяет строительство. Для солдат нужны казармы, для техники — завод.
Нажав «Нанять», выберите точку: подготовленный отряд придёт туда самостоятельно.
«Гарнизон» задаёт желаемое количество — гарнизон пополняется за ресурсы.

В арсенале «Произвести» ставит конечный заказ на выбранное количество.
Нужны соответствующие производство, склад, пусковая и физическое снабжение.
«Пуск» включает наведение по карте, ЛКМ запускает выбранную партию.
Shift+ЛКМ — промежуточная точка маршрута. ПКМ — отмена.
Морская база ставится на побережье, корабли загружаются у причала.

Сохранения: %APPDATA%/Godot/app_userdata/Небесный рубеж — Native/
Правила игры сохранены из версии 8.16. Нативное изображение, интерфейс,
управление и звук работают в Godot/C#. Локальная симуляция пока использует
упакованное JS-ядро: это первый этап миграции, а не полный перенос правил на C#.
Сетевой интерфейс и все расширенные инструменты прежнего браузерного UI ещё
не перенесены. Старую браузерную игру и её сохранения пакет не изменяет.

Лицензии движка, Node.js и ресурсов — в папке licenses и в данных игры.
