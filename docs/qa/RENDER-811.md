# Поселения и пакетная отрисовка 8.11

Нейтральные городки используют существующие модели `housing` и `industry`, общий план въездной улицы и заметный маркер её конца. После `materialized` превью удаляется: реальные здания и дороги рисуют обычные системы мира. Общая геометрия при удалении превью не освобождается. Карточка показывает фактический доход, состояние дороги, число действующих зданий и разрушение.

Обычные статичные здания используют общие шаблоны по типу, стороне и уровню. Непрозрачные части объединены в `BuildingBatch`; отдельные объекты сохраняются для выбора, стройки и разрушения. Динамические турели и прозрачные световые пятна остаются в прежнем рендере. В экземпляры попадают здания в камере **или** во фрустуме тени солнца. Неизменные кадры не загружают повторно те же матрицы.

## Замер 500 объектов

Изолированный Chrome/SwiftShader, 1280×720, pixel ratio 1. Четыре города: 320 зданий и 180 наземных единиц. Обычная камера над своим штабом, расстояние 720. Восемь измеряемых кадров после прогрева. Исходный путь моделировался отключением нового кеша обычных зданий и пакетной отрисовки в том же fixture. Геометрия, освещение и камера сохранены.

| Метрика                         |      До |   После |
| ------------------------------- | ------: | ------: |
| Draw calls                      |     896 |     556 |
| Треугольники                    | 534 216 | 534 216 |
| Геометрии, загруженные WebGL    |     359 |     109 |
| Первичная синхронизация, мс     |  2660,6 |  1590,7 |
| Кадр с `gl.finish`, медиана, мс |    83,4 |    83,0 |
| Кадр, максимум из 8, мс         |   162,9 |   110,7 |

В финальном кадре включены 79 из 316 подходящих зданий, 23 пакета. Остальные города отсечены камерой и тенью; исходные объекты для выбора сохранены. Снижение числа вызовов и геометрий подтверждено. Ускорение медианного GPU-кадра практически отсутствует; это не измерение FPS на реальном пользовательском GPU.

Синхронизация дала 5,5 → 13,4 мс, но финальный прогон пересекался с CPU-тестами; эти цифры не считаются изолированным сравнением CPU. Отдельный ранний диагностический обзор всех городов показал 4973 → 3607 вызовов и 1301 → 301 геометрию, также без доказанного улучшения медианного кадра SwiftShader. Обычные ограничения камеры не изменялись.

Артефакты: `artifacts/qa/render500-baseline-home.json`, `render500-optimized-home.json`; дополнительные обзорные замеры — `render500-baseline.json`, `render500-optimized.json`. Первую попытку с камерой над морем исключили из сравнения.

## Проверки

Профильные Node-проверки покрывают общую геометрию, сохранение выбора, тени, скрытие разрушенного содержимого, очистку пакетов, отсутствие повторной загрузки матриц, отсечение вне обеих камер, уровни оснащения, маски городков и удаление нейтрального превью при присоединении. Карточки проверены для нейтрального, отключённого и разрушенного городка. Список использует один временный `Map` экономик и не вычисляет экономику для нулевого выпуска.

Интерактивную проверку въезда, присоединения, удара по зданиям и финального внешнего вида выполняет отдельный браузерный QA; этот замер её не заменяет.
