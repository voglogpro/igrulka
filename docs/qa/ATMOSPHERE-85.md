Проверены автономный файл без сети и исходные модули по HTTP; ошибок JS и шейдеров нет.
```sh
npm run check
npm run test:soak
node tests/soak/city-services.mjs
node --test tests/unit/weather.test.mjs tests/unit/weather-rendering.test.mjs tests/unit/audio-atmosphere.test.mjs
node --test tests/unit/ballistic-tracers.test.mjs tests/unit/network-ballistics.test.mjs
node --test tests/unit/city-services.test.mjs tests/unit/service-rendering.test.mjs tests/unit/network-services.test.mjs
python tests/browser/audio.py --wav --compare dc63e9b
python tests/browser/smoke.py
python tests/browser/atmosphere.py
```

Перед браузерной проверкой нужна актуальная сборка (`npm run build`; её также выполняет `check`). Тяжёлые 3D-сценарии запускаются последовательно.

Ограничения: ремонтные машины не имеют собственного HP — флот теряется при уничтожении станции; очереди гражданского движения и заторы между автомобилями не рассчитываются. Проверка LAN/кооператива не означает готовность Steam или публичного интернет-сервиса. Программный SwiftShader не даёт оснований обещать производительность на пользовательском GPU или качество звучания физических колонок.
