# Native unpaused battle fixture

Prepare with `node scripts/prepare-native-battle-qa.mjs`. Add `--preflight` to execute sixty simulation seconds through the original CPU engine before a native run. Output stays in ignored `artifacts/native/battle-qa/`.

The fixture places 500 factory-default ground groups, 250 per side, on valid dry positions at both land corridors. This density is synthetic and unpaid. No HP, ammunition, cargo, stock, level or resource grants are applied. Before placement, both sides buy power, housing and ammunition production through original build commands and complete 600 normal construction ticks. Attack-move orders use the original deferred path planner. The original two-human mode supplies autonomous combat/support behavior without editing global AI timers; this is not a bot economic-difficulty or multiplayer test.

Pass `artifacts/native/battle-qa/native-battle-qa.generated.js` to the native client's `--qa-script` option. The script imports through the original file input and page reload, checks constructor fields, then runs the original game unpaused for sixty wall-clock seconds. It never calls `E.step` or changes simulation speed in the browser. It observes movement, actual shots/projectiles, damage, ammunition use, reloads, medic patients and healing, supply vehicles, crates, native ACKs and browser long tasks. Camera moves to the second corridor after thirty seconds. The final report includes elapsed simulation time and its ratio to wall time; no frame-rate threshold is hidden behind the functional result.

The CPU preflight passed with 5,171 observed shots, 494 groups moving, 402 wounded, 40 simultaneously reloading, 18 medics acquiring patients and 111 observations of actual HP increases. Four physical supply vehicles were observed; no completed crate delivery occurred within sixty seconds. Those are separate results. Only 96 groups survived: losses are real source combat outcomes and are not replenished or hidden to hold an artificial constant entity count.

This fixture exercises dense real combat after a synthetic initial placement. It does not prove paid recruitment, sustained 500-unit survival, public network performance, subjective audio quality or smooth frame pacing. The native GPU run is performed separately by the main agent; preparation and CPU preflight alone are not a native runtime pass.
