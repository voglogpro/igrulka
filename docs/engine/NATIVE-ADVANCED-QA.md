# Нативная проверка транспорта и морского снабжения

Сценарий проверяет исходные кнопки армии, посадку и высадку БТР, производство крылатой ракеты, физический подвоз, морской пуск и возвращение корабля. Основа — город, построенный обычными оплаченными командами и `E.step`, с сохранением исходных сроков, ресурсов, HP и боезапаса.

Подготовка из корня репозитория:

```powershell
node scripts/native-parity-paid-advanced-fixture.mjs --run
node scripts/prepare-native-paid-advanced-qa.mjs
```

Без `--run` первый скрипт выводит план и не запускает симуляцию. Результаты остаются в игнорируемой папке `artifacts/native`: три сохранения `paid-advanced-{ready,boarded,complete}.json`, отчёт `paid-advanced-report.json` с командами и списаниями и подготовленный `parity-paid-advanced-qa.js`.

Для нативной проверки нужен проверяемый полный Windows-пакет. Передайте его `Skyfront.exe` отдельный QA-сценарий:

```powershell
$qaFile = (Resolve-Path artifacts/native/parity-paid-advanced-qa.js).Path
$captureFile = Join-Path (Get-Location) artifacts/native/paid-advanced-viewport.png
& 'C:/path/to/Windows-package/Skyfront.exe' -- --qa-parity "--qa-script=$qaFile" "--capture=$captureFile"
```

QA-профиль отделён от обычного сохранения игрока. Сценарий использует исходный импорт файла с настоящей перезагрузкой, DOM-кнопки и обработчики приказов. Он сверяет пассажиров, видимые экземпляры пехоты, оплату, склад, груз машин, запас корабля, координаты пуска и подтверждения сцены Godot. Промежуточные записи `SKYFRONT_PARITY_WEB_QA` показывают этапы; итог должен содержать `stage:"complete", passed:true`. Ошибки нельзя заменять успешным выходом процесса или одним изображением viewport.

Это локальная интеграционная проверка: исходный режим `multiplayer` содержит второго бездействующего человека и штатно отключает ботов. Сетевого подключения в этом сценарии нет. Время ускоряется исходным `E.step` при паузе, поэтому результат не доказывает FPS реального боя, конкурентный баланс, внешнюю интернет-сеть, физический диалог Windows или качество прослушивания звуков. Синтетическая галерея моделей для этого сценария не используется.

Полная матрица и фактические результаты приёмки находятся в [PARITY-816.md](PARITY-816.md).
