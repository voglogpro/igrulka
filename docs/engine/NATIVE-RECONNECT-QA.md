# Нативная проверка восстановления связи

Сценарий запускает один настоящий native-клиент и исходный Node `NetworkSession` host с исходным `createRoomServer({ autoTick: true })` на loopback. Сначала оба игрока оплачивают постройки; МОГ получает исходный ненулевой боезапас. Затем проверка закрывает настоящий native WebSocket кодом 4000 и ждёт исходного автоматического восстановления. Игровые таймауты, backoff, ресурсы и симуляция не меняются; ручных ticks и поддельного транспорта нет.

Из корня репозитория:

```powershell
# Только подготовка JS, без сервера и GPU:
node scripts/native-parity-reconnect.mjs --prepare-only --output artifacts/native/reconnect-prepare

# Настоящие исходные Node-клиенты, без GPU; это только CPU preflight:
node scripts/native-parity-reconnect.mjs --cpu-preflight --output artifacts/native/reconnect-cpu

# Один настоящий native-клиент, полный Windows-пакет:
node scripts/native-parity-reconnect.mjs --run-native --exe native/build/parity-windows/Skyfront.exe --output artifacts/native/reconnect-native
```

Папка `--output` должна быть новой. В ней сохраняются `report.json`, исходный QA JS и отдельные `native-guest.out.log`/`native-guest.err.log`. Координатор управляет только созданным им дочерним процессом. Нативный успех требует итогового `passed:true` у гостя и authority, штатного выхода клиента с кодом 0 и пустого stderr; один успешный код выхода недостаточен. `--prepare-only` и `--cpu-preflight` не подтверждают работу native-клиента.

Проверяются точный hash полного состояния, tick, время, RNG, бюджеты, боезапас и ID построек в окне разрыва; исходная пауза интерфейса; возврат в ту же комнату и место; сохранение последовательности команд; новая оплаченная стройка и отказ в управлении чужой постройкой после восстановления. Затем выполняются сверка сцены Godot через ACK и исходный выход с восстановлением одиночной кампании. Бюджет клиента сравнивается с конкретным реально сериализованным серверным снимком, до интерполяции отображения. Секретные токены остаются внутри наблюдателя; в отчёте выводится только результат сравнения.

Это приёмка короткого разрыва настоящего WebSocket на одном компьютере. Она не доказывает работу публичного интернета, длительного отключения, перезапуска сервера или стабильный FPS. Полная матрица — [PARITY-816.md](PARITY-816.md).
