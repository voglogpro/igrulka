# Графический этап 0.3: земля и глубина

База — принятый полный перенос Native 0.2.1, браузерная 8.16 `68580f0`.
Ветка — `codex/native-atmosphere-03`. Большая очередь моделей и эффектов
остаётся в [GRAPHICS-02.md](GRAPHICS-02.md); здесь описан первый фрагмент.

## Реализация

- `Parity/TerrainPresentation.cs`, `terrain-pbr.gdshader`: два общих 1K PBR
  набора CC0, приглушённая земля, крупная вариация, мокрый грунт по исходной
  погоде и фильтрация мелкого рельефа вдаль.
- `Parity/TrenchPresentation.cs`, `TrenchGeometry.cs`, `TrenchCutoutAtlas.cs`:
  18-метровые секции с дном до 1,55 м, откосами, торцевыми спусками, досками,
  подпорками и бруствером. Редкая маска вырезает землю внутри исходного следа
  окопа. Общие MultiMesh по уровню и сектору имеют собственные границы.
  Маска перестраивается при изменении формы, а не при каждом кадре копания.
- `native/parity/visual-bindings.mjs`: явные read-only ссылки на исходную
  землю и видимые фортификации, без определения объектов по цвету.
- `trench-presentation.mjs`: общий визуальный пол бойцов, МОГ, раненых,
  тел, теней, выбора, вспышек и трассеров. Положение крайних членов группы
  проверяется отдельно. Физические координаты, защита и урон не меняются.
- `presentation-transform.mjs`: нативная сборка применяет точные проверяемые
  замены только в rendering-модулях. Перечень находится в `PARITY-BUILD.json`;
  браузерные файлы `src` остаются исходными.
- `WarAtmosphere`: согласованный свет без автоматической экспозиции, низкая
  дымка с исключением неба и слабое неполосатое зерно. Направления света,
  время суток, погода и звук сохраняются.

## Проверка и пределы

Первый standalone-прогон исходного оплаченного сценария прошёл 46/46,
exit0, stderr пуст. Первый визуальный сценарий прошёл enhanced 78/78 и
baseline 68/68, оба exit0: исходный импорт, точное сравнение сохранения
после отрисовки, выбор опущенного бойца, четыре секции на ровной земле
и настоящих склонах. Временные день/ночь/погода явно синтетические
и полностью восстанавливаются.

Первый внешний вид был отклонён: просмотр PNG выявил бежевый пересвет
и повтор мелкого рельефа. Исправленный материал сжимает дневной свет,
приглушает палитру и отключает дальние normals/ARM. Повторный нативный
прогон `terrain-artpass2` прошёл **81/81**, exit0, stderr пуст; все три
PNG просмотрены. Дневной пересвет устранён, земля стала серо-оливковой,
мелкий повтор ослаблен. Это приёмка первого материала и секций, не всех
моделей и эффектов большого обновления.

Соединительные участки траншей, крытые блиндажи и бетонные форты пока
сохраняют прежнюю графику. Новые GLB техники и пехоты ещё не подменяют
исходные модели. Навигация через специальные входы не добавлена: это
отдельное изменение механики, а не только движение видимой модели.

CPU: `node scripts/native-presentation-check.mjs` и
`dotnet run --project tools/native-trench-checks/NativeTrenchChecks.csproj`.
GPU: `node scripts/prepare-native-terrain-qa.mjs`, затем
`--qa-script=".../artifacts/native/terrain-qa/native-terrain-qa.generated.js"`
и `--capture=".../terrain.png"`. Для исходного вида добавить
`--baseline-graphics`. PNG содержат собственный Godot viewport;
DOM-интерфейс находится в отдельном слое окна.

Первый общий p95 около 30,56 мс enhanced / 16,67 мс baseline включает
загрузки и синхронные PNG readback. Это ориентир стоимости эффектов,
не чистый фазовый benchmark и не доказательство массового боя.
Последующая правка требует повторного сравнения; стабильный FPS
при любом числе юнитов не обещается.

Полный `npm run check` прошёл повторно: **1151/1151**, 197188,6 мс,
exit0. Новый presentation CPU-check — 37 проверок; geometry/atlas — 758.
Дальнейший dev art-pass зарегистрировал общий p95 25,36 мс, но сборка
Debug и дополнительная диагностика отличаются от прежнего Release A/B;
это число не считается прямым сравнительным benchmark.
