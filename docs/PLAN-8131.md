# 8.13.1: атмосфера звука и проект экономики

База — опубликованная 8.13 (`7d528c9`). Старые готовые версии, серверы и комнаты
сохраняются. Это два отдельных результата по новым сообщениям пользователя.

## Экономика — проект следующего изменения правил

- [x] Прочитать настоящие формулы, цены, производство, содержание, торговлю,
      пополнение и интерфейс. Отделить факты от проектных решений.
- [x] Сопоставить полезные принципы других стратегий с нашей игрой; сохранить
      четыре ресурса и показатель мощности, без возврата исследований.
- [x] Рассчитать понятные цепочки и варианты расходов, найти противоречия,
      начальный тупик восстановления, бесплатные комплекты и скрытые потоки.
- [x] Сохранить проект, пример развития, порядок реализации и приёмочные сценарии.
      Будущие цены не выдавать за уже внедрённый и проверенный баланс.

Результат: [проект экономики](design/ECONOMY.md), воспроизводимый статический
расчёт `node scripts/economy-report.mjs`. Арифметика проверена независимо;
сценарный баланс будущих правил не заявляется.

## Звук — реализация и отдельный выпуск

- [x] Разделить записанные и существующие синтетические источники; найти реальные
      лицензированные кандидаты для основных взрывов, не придумывать источники.
- [x] Сделать значимые пуски/артиллерию/взрывы слышимыми через море: дистанционный
      фильтр, бас и отражения существующего сигнала. Общий master не повышать.
- [x] Сохранить перспективу, скрытность, фиксированные пулы/лимиты голосов,
      throttle, mute/pause и подготовку без fetch/decode во время боя.
- [x] Проверить настоящим WebAudio дальние и ближние события, несколько залпов,
      клиппинг, хвосты, запуск/паузы, отсутствие новых боевых аллокаций буферов.
- [x] Выполнить check, собрать и проверить автономный HTML. Честно отделить
      цифровую проверку от прослушивания; сохранить измеренные ограничения.

Распространение выполняется из зафиксированного коммита: отдельная готовая папка,
её HTTP/WebSocket-проверка, CI/Pages и сравнение публичного SHA-256 с испытанным
HTML. Версия 8.13 сохраняется. Фактическая приёмка выпуска записывается после
этих действий в `artifacts/qa/8131-release-acceptance.json`, а не отмечается заранее.

## Следом — цельные окопы вместо ямок

Дополнение пользователя после заданий экономики и звука. Сначала завершить эти
этапы, затем реализовать исправление окопов; исследование допустимо заранее.

- [x] Изучить визуальные музейные референсы и текущую геометрию. Отдельные короткие
      ямки отвергнуты: нужна одна непрерывная секция около 15–20 игровых метров.
- [x] Сделать цельные земляные секции для группы с промежутками или соединениями,
      естественными краями и читаемой внутренней частью. Сохранить бюджет batches.
- [x] Проверить укрытие бойцов по всей действующей секции, вместимость, повторное
      занятие после потерь, захват и назначение мест новому пополнению. Отдельная
      система HP/разрушения окопа не вводится: гибель бойца сохраняет земляные работы.
- [x] Проверить вид с игрового ракурса днём/вечером и при близкой камере, нагрузку
      большой армии, сохранение и кооператив. Фотография тестового ракурса сама по
      себе не доказывает работу защитной механики.

## Дополнение — атака без боеприпасов

Пользователь наблюдает остановку после прихода к городу и расхода магазина.
Не считать один тест доставки доказательством непрерывного снабжения армии.

- [x] Воспроизвести нехватку боезапаса перед выходом и в глубине вражеского города
      с обычными оплаченными бойцами, конечными складами и реальными маршрутами.
- [x] Перед выходом проверять готовность; пополнять физически, показывать причину
      ожидания. Не записывать бесплатные патроны и не телепортировать снабжение.
- [x] После истощения искать доступный конечный запас/подвоз, разумно отходить за
      ним и продолжать исходную атаку. При отсутствии боеприпасов ждать с причиной
      или возвращаться, а не стоять без объяснения у чужого здания.
- [x] Проверить ручной приказ/отзыв, потерю склада/машины/цели, переполненный путь,
      несколько целей подряд, save/load, бота и кооператив без дополнительных
      пересчётов маршрутов на каждом кадре.
