# Проверяемый чеклист требований пользователя

Срез разработки 8.9.1: целевые schema 16 / protocol 9 ещё проходят интеграцию. Финальные номер пакета, сборка и portable HTML подтверждаются root. «Готово» означает наличие реализации и указанной проверки, не отсутствие всех ошибок. Качественные обещания звука/дизайна не следуют из тестов. «Доделывается» требует сообщения владельца и проверки интеграции. Пути относительны корню репозитория.
