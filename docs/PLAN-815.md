# 8.15.0 — снабжение, флот, новые ракеты и значки проблем

## Запрос

Подвоз дронов и ракет к пусковым идёт долго и непонятно. Проверить, что рынок
действительно приносит деньги. Ящики с боеприпасами: больше круг пополнения,
повторный подвоз, машины подъезжают к ушедшим вперёд бойцам, ящики можно
захватывать и уничтожать. Добавить корабли с крылатыми ракетами и разнообразие
ракет. Усложнить производство ракет и электроники, ослабить баллистику (два
попадания ЗРК, без обломков) и сделать понятные значки нехватки, как в
градостроительных играх.

## Что найдено и сделано

| Задача            | Причина / решение                                                                                                                                                                               |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Подвоз к пусковым | Завод собирал по одному изделию, машина везла 1 дрон к ближней площадке, поиск маршрутов был общим на всю игру (4/с). Линии 2–4, полный комплект, честная доля, бюджет на сторону, скорость 40. |
| Ящики             | Радиус похода к ящику не применялся: бойцы шли к ящику другого коридора вокруг моря. Пост — 260 м, атака — 700 м; круг 60 м; захват.                                                            |
| Рынок             | Караваны ехали только к рынку врага через фронт: без рынка у врага дохода нет, в бою караваны гибнут. Оборот с домами, караваны в свои поселения.                                               |
| Флот              | `navalbase`, `s.warships`: погрузка у причала, огневая позиция в море, потопление и платная замена.                                                                                             |
| Ракеты            | `stealth`, `tactical`, `cluster`; семейства оружия; заметность для ПВО.                                                                                                                         |
| Баланс            | Баллистика 130 HP (два попадания по 68), ракеты не падают обломками; электроника 8 с/ед., ракеты 10–18 эл.                                                                                      |
| Подсказки         | `problemMarkers`/`problemSummary`, значки над зданиями и группами бойцов, сводка-кнопка.                                                                                                        |

## Проверки

- `npm run check` и `npm run test:soak` (12 кампаний × 20 минут).
- Целевые тесты: `logistics-815`, `market-815`, `weapons-815`, `naval-815`,
  `problems-815`.
- Браузер: значки и сводка на сохранении с проблемами, без ошибок консоли.

## Ограничения

- Корабль не имеет собственного ПВО; его защищают ЗРК берега.
- Значки обновляются дважды в секунду и показывают только первую проблему здания.
