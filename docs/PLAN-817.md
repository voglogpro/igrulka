# 8.17.0 — большая война

Запрос: больше масштаба и экшена; карта «сильно больше»; дороги через горы; режим «все против
всех» на четырёх равноценных позициях с ботами разной силы; «Начать бой» должен идти со всех
направлений, а не с одного фланга; авиация со сбросом ФАБ; корабли покупаются, дорогие, с
пулемётными точками против дронов и шахтой для запуска дронов; дешёвый катер против большого
корабля.

## Ограничения

- Позиции «все против всех» — существующие четыре города; они симметричны, но расстояние через
  море больше, чем вдоль берега.
- Браузерная проверка выполнялась в программном WebGL (SwiftShader): ошибок нет, кадры не
  являются замером производительности.
